One emoji, one dream vacation: the northern lights — the one night you would cross the world for.

> 🌌

## Run it

```sh
python3 main.py --self-test
python3 main.py
```

`main.py` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it (exactly one emoji — a single code point in the emoji ranges, no whitespace, no variation selector, no joiner, no modifier — stricter than the kit gate, which requires only 1–8 non-whitespace UTF-8 characters), and reads it back to confirm the file holds exactly the entry. Standard library only, deterministic, no network, no clock.
